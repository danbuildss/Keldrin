# Strategy
Positioning source of truth: POSITIONING.md (approved 2026-11-28). Keldrin is the verified intelligence infrastructure for tokenized equities, starting with Coinbase's tokenized stocks on Base; an infrastructure provider, not a competitor to the applications it serves. Base is the starting ecosystem, not a limit.

Position: intelligence layer for programmable equities. Initial wedge: verified corporate-event feed linking real company disclosures to exact Base token contracts. Customers: Base stock builders, financial research agents, applications. Sell normalized, cited, reusable intelligence; do not sell public raw data as unique value.

Compounding loop: discover → extract → verify → normalize → store → serve → collect developer feedback → correct → evaluate. Defensibility hypothesis: point-in-time archive, asset mapping, evidence lineage, event coverage and reliable integrations. Validate with developers, not follower counts alone.

Non-goals: trading bots, lending, portfolio management, price oracle replacement, generic news aggregator, token launch and broad multi-chain coverage in MVP.

Reference competitor: BStocks already provides a public market-data API. Audit corporate-event coverage and developer workflow gaps before asserting differentiation. Compare financial-data APIs and issuer data; never claim unique or first without evidence.
