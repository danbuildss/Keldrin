# Company logos

Source: the open-source [Simple Icons](https://simpleicons.org) set, npm package `simple-icons@15.22.0`
(icon data CC0-1.0), with each brand's colour from the same package.

These logos are trademarks of their owners. keldrin shows them only to identify the company behind each
tokenized stock, and is not affiliated with or endorsed by them. Amazon and Microsoft have asked Simple Icons
not to include their logos. Sandisk has no icon in the set, and the MicroStrategy icon predates the company's
rename to Strategy. Those four stocks show a ticker badge instead.

To remove a logo, delete its file. The page then falls back to the ticker badge.
