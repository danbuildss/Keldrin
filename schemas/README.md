# Proposed schema and fixtures
The JSON Schema is draft 2020-12, not a final API contract. Numeric facts use exact decimal strings with explicit units. Synthetic fixture must never be released. Production validation must additionally verify evidence cross-references, source rights, nonzero contract and issuer mapping, independent review bound to the immutable candidate hash (review metadata stored separately), correction logic, and freshness. Schema alone cannot establish authenticity or release permission. `scripts/check_kit.py` checks basic structural invariants and uses jsonschema if installed; CI installs it. Add real gold fixtures only after evidence and rights checks. No real source values are present here.
